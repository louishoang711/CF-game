CROSSFIRE LEGENDS — EVENT ASSETS
=================================

Keep these filenames when replacing the event artwork:

logo.jpg          CrossFire Legends logo shown in the interface
dongdau.jpg       Step 2: the stamp-zone artwork
hopgauCFL.jpg     Prize: Hộp Gấu CFL
mockhoaCFL.jpg    Prize: Móc khóa CFL
stickerCFL.jpg    Prize: Sticker CFL
tuiCFL.jpg        Prize: Túi CFL

Recommended dimensions for the card and prize images are 1200 × 1600 px
(3:4 portrait). The app selects one of the four prize images using the
chancePercent values in src/eventConfig.ts after the card is stamped.
